# MyGiftCards data site

Served at <https://naveh92.github.io/MyCards/> and read by the app, not by people.

- `catalog.json` — the card types the app offers, and where each one's merchant list comes
  from. The app takes whichever copy declares the higher `catalogVersion`, this one or the
  one compiled into the APK, so publishing a higher version here adds a card type to phones
  already installed **without an app release**.
- `stores/*.json` — one merchant list per card type.
- `manifest.json` — sha256 and merchant count for every file above. Phones fetch this first
  and skip anything whose hash has not moved, so an unchanged week costs one small request
  instead of several megabytes.
- `privacy.html`, `index.html` — the only pages meant for a human.

`.nojekyll` is deliberate. Nothing here uses Jekyll, and leaving it enabled means every push
waits on a site build that can only add latency and failure modes to a folder of static JSON.

Most of this directory is regenerated by `.github/workflows/refresh-store-lists.yml` every
Monday. That job rsyncs with `--delete`, so a hand-maintained list must be named in its
"Keep the hand-maintained lists" step or it is removed from the site on the next run.
